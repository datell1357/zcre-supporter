# ZCRE 서포터

ZCRE 크레딧과 생성 작업을 살펴보는 macOS 바탕화면 토끼 앱. SwiftUI + AppKit으로 구현한 0.2.20 출시 준비 후보입니다. 사용자 제공 시트에 맞춘 검정 비니 지크와 ZCRE 웹의 검정·차콜 테마를 사용합니다. 공개 배포 준비 상태와 남은 조건은 [배포 안내](docs/RELEASE.md)를 확인하세요.

첨부 캐릭터를 바탕으로 Grok과 sprite-gen으로 만든 대기·산책·드래그·작업 중·완료·실패·손 흔들기 모션을 사용합니다. 대기/산책/드래그는 반복하고, 완료는 활짝 웃으며 연속으로 뛰는 동작을 약 2.7초간 한 번 재생한 뒤 돌아옵니다. 실패 시에는 주저앉아 양손으로 눈을 비비고 옆으로 눈물을 흘리는 약 5초 모션을 한 번 재생합니다. 완료·실패 동작 중에는 산책 이동을 멈춥니다. 빌드에 필요한 모션과 효과음은 `Sources/ZCREBunny/Resources`에 포함되어 있습니다. 원본 제작물과 홍보영상은 이 저장소에 포함하지 않습니다.

## 실행

1. `dist/ZCRE 서포터.app` 또는 `Run ZCRE 서포터.command`를 실행합니다.
2. 첫 실행의 현황판에서 **ZCRE 계정 연결**을 눌러 앱 안의 ZCRE 웹 창에 로그인합니다. Codex 브라우저의 로그인 상태와는 별도입니다.
3. 지크를 누르면 크레딧·동시 생성 현황과 원형 도구 메뉴를, 메뉴 막대 지크를 누르면 진행 작업·크레딧·최근 알림·서비스 상태 패널을 엽니다. 이후 시작은 상단 바에서 조용히 이뤄지며, 이미 실행 중인 앱을 다시 열면 현황판이 표시됩니다.
4. 현황판에 잔액이 나타나면 연결된 것입니다. 로그인 창을 닫아도 앱이 켜져 있으면 계속 확인합니다.
5. 첫 실행에서 macOS가 알림 허용 여부를 묻습니다. 거절했거나 꺼진 경우 현황판/설정의 **알림 설정 열기**가 ZCRE 서포터 전용 알림 설정으로 이동합니다. 설정에서 허용 여부를 직접 선택할 수 있고, 앱으로 돌아오면 상태가 갱신됩니다. 시스템 알림을 허용하지 않아도 앱 내 알림은 동작합니다.
6. 메뉴 막대 클릭 → **지크 숨기기**, 또는 우클릭 → **지크 숨기기**를 선택하면 캐릭터만 사라집니다. 같은 위치에서 **지크 보이기**로 복원합니다. 크레딧 조회와 작업 감지는 계속됩니다.

로그인 없이 **연결 전에 미리 둘러보기**로 토끼와 현황판, 완료 상태 전환을 체험할 수 있습니다. 미리보기의 숫자·작업은 가상 데이터이며 실제 크레딧은 사용하지 않습니다.

## 기능

- 투명한 바탕화면 토끼: 상하좌우·대각선 8방향 중 방향·거리·휴식 시간을 무작위로 고르는 산책. 모든 방향의 이동 속도와 걸음 주기는 같습니다. 우클릭 메뉴와 위치 복원을 지원합니다.
- 드래그하면 몸과 무릎을 접으며 대각선으로 버둥거립니다. 눈·입·귀·앞발·뒷발이 크게 반응하고, 뒤쪽 목덜미가 커서에 붙습니다. 좌우 이동에 따라 같은 모션을 반전하며, 작은 마우스 떨림에는 방향을 유지합니다. 화면 테두리에 막히지 않고 놓은 위치를 그대로 유지합니다.
- 메뉴 막대: 사용 가능 크레딧, 클릭하여 현황판 열기. 대기/생성 중 작업이 있으면 토끼가 달리고, 모두 끝나면 멈춥니다. 전용 네 발 달리기 모션을 12프레임으로 캐시해 약 0.58초 주기로 반복하며 별도 팔다리를 그려 넣지 않습니다. 크레딧 표시 끄기 지원.
- 작업이 대기/진행 중이면 바탕화면 지크는 산책을 멈추고 불꽃을 두른 채 노트북을 두드립니다. 드래그와 완료 동작이 우선하며, 완료 모션 후 남은 작업이 있으면 타이핑으로 돌아갑니다. 작업 자세는 지크가 있는 화면의 중앙을 향합니다. 오른쪽에서는 왼쪽을, 왼쪽에서는 오른쪽을 보며 원본을 좌우 반전해 사용합니다. 모션은 번들 리소스만 사용하므로 추가 웹 요청을 만들지 않습니다.
- **설정 → 지크 효과음**에서 소리를 켜거나 끄고 음량을 0–100%로 조절합니다. 기본은 켜짐·35%입니다. 홍보영상의 붙잡힘 소리는 드래그 시작 때 한 번, 타자 소리는 실제 작업 또는 디버그 작업 모션 중 약 1초 재생 후 5초 쉽니다. 다른 앱의 재생·통화를 감지하면 타자를 멈추고 조용해진 뒤 재개합니다. 드래그·완료·실패 모션에서도 타자가 멈춥니다. 지크 숨김·Mac 잠자기·음소거·0% 음량·앱 종료 시 소리는 멈춥니다. 모든 소리는 번들 WAV이며 추가 웹 요청은 없습니다. 타자음이 필요한 동안만 짧은 예약 작업으로 오디오 사용 여부를 확인하며, 쉬는 구간에는 플레이어를 해제합니다. 다른 앱의 오디오 내용은 캡처하지 않고 장치·시스템 음량도 바꾸지 않습니다. macOS 알림 소리 설정은 별개입니다.
- 토끼 클릭 카드: 현재 크레딧, 이미지/영상 작업 수와 동시 생성 한도, 합산만 표시합니다. 토끼가 있는 모니터의 여유 공간에 맞춰 위·아래·좌우로 열립니다. 진행 개수는 모든 화면에서 동일한 최신 API 작업 목록으로 계산하고, 웹 화면에서는 한도만 사용합니다. 한도를 확인할 수 없으면 실제 조회한 작업 수만 표시합니다.
- 메뉴 막대: 현재 크레딧·작업 중 개수, 지크 숨김/표시, 최신 알림 10개. **상세 현황**에서 사용 가능·예약·총 크레딧과 작업 기록을 엽니다.
- 메뉴 막대와 지크 클릭 카드는 별도 팝오버로 관리하며 한 번에 하나만 엽니다. 메뉴 막대의 **최근 알림**은 최신 10개만 표시합니다. **상세 현황** 또는 **알림 전체 보기**를 누르면 보관된 전체 알림(최대 30개)을 상세 창에서 볼 수 있습니다. 알림이 없어도 제목과 연결 대기·빈 기록·지운 기록에 맞는 안내를 표시합니다.
- 메뉴 막대 현황판을 670×560pt 두 열로 구성합니다. 왼쪽은 크레딧·작업·최근 알림, 오른쪽은 **서비스 상태**입니다. 화면이 작으면 사용 가능한 공간에 맞춰 크기를 줄입니다. ZCRE 상태 페이지의 공개 데이터를 조회해 서비스별 정상·지연·오류 증가·확인 중 상태와 KST 집계 시각을 표시합니다.
- 서비스 상태는 현황판이 열린 동안 1분마다 갱신하며 재개방에도 60초 캐시를 사용합니다. 수동 갱신도 최소 5초 및 서버의 재시도 대기를 따릅니다. 서버가 지원하면 조건부 요청으로 같은 본문을 다시 받지 않습니다. 닫기·잠자기 때는 중지하며 수동 새로고침과 **ZCRE 상태 페이지 ↗**를 제공합니다. 조회 실패, 서버의 오래된 집계 표시, 집계 시각이 서버 시각과 5분 넘게 차이나는 경우에는 정상 표시를 유지하지 않고 확인 중으로 전환합니다.
- 설정은 지크 보이기/숨기기 바로 아래에 배치합니다. 지크 우클릭의 산책 메뉴는 현재 상태에 따라 **산책 활성화 / 산책 비활성화**로 표시합니다.
- 새 완료 알림은 모델·작업 종류와 시작 시각을 표시합니다. 예: 말풍선은 **Topaz 영상 업스케일 / 20:19 시작 · 작업 완료**, 시스템 알림 제목은 **Topaz 영상 업스케일 완료**입니다. 실패 알림도 같은 기준으로 작업을 구분합니다. 과거에 저장된 알림 문구는 유지합니다.
- 지크를 숨기면 완료·실패·크레딧 부족을 상단 바 아래의 8초 배너로 알립니다. 여러 작업이 한 번에 끝나면 배너 하나로 합치고 각 알림은 목록에 보관합니다. 배너는 다른 앱의 키보드 포커스를 가져오지 않습니다.
- 상단 바에는 지크 아이콘과 크레딧만 표시하고 읽지 않은 알림 숫자는 붙이지 않습니다. 상단 바에서는 표시하는 최신 10개를, 상세 현황에서는 전체 목록을 읽음 처리합니다. 최근 30개는 이 Mac에 저장하며 같은 계정 확인 후 복원합니다. 계정이 바뀌면 해당 계정의 기록으로 교체하고, 연결 해제는 로컬 기록도 삭제합니다. 미리보기 기록은 저장하지 않습니다. 시스템 알림 클릭도 이 목록을 엽니다.
- 계정 연결 시 기존 완료·실패 작업도 최근 알림에 가져옵니다. **기존 기록 · 시작**은 서버가 제공한 작업 시작 시각이며 완료 시각이 아닙니다. 과거 기록에는 새 배너·소리·읽지 않은 표시·완료 모션을 실행하지 않습니다. 새로 감지한 완료/실패와 잔액 임계값 알림은 기존 설정을 따릅니다.
- **전체 지우기**는 보관된 목록 전체를 비우며 재실행해도 유지됩니다. 지우기 이전에 시작된 과거 작업은 다시 가져오지 않지만, 실행 중 감지하는 새 상태 전이는 계속 알립니다.
- 설정: 지크 표시·산책·크기(70–150%), 상단 바 배너·알림 종류·소리·크레딧 임계값, 계정 연결 해제. 지크를 숨기거나 잠자기에 들어가면 캐릭터 재생·이동 타이머를 멈춥니다.
- **설정 → 앱**에서 로그인 시 자동 실행을 직접 켜거나 끌 수 있습니다. 기본값은 자동 실행을 등록하지 않습니다. 응용 프로그램 폴더에 설치한 뒤 설정하세요. 승인 대기 상태에서는 로그인 항목 시스템 설정을 엽니다.
- **진단 정보 내보내기**는 앱·운영체제 버전, 연결 상태와 작업 개수만 JSON으로 저장합니다. 계정, 잔액, 작업 ID·프롬프트·결과 URL·인증 정보는 제외하며 자동 전송하지 않습니다.
- **설정 → 디버그 모드 → 디버그 모드 활성화**에서 `zcrenext`를 입력하면 **지크 모션 테스트 열기**가 나타납니다. 평소에는 모션 테스트 버튼과 지크·상단 바 우클릭 메뉴의 테스트 항목을 숨깁니다. 디버그 모드는 저장하지 않으며 앱을 종료하면 꺼집니다.
- 모션 테스트는 스크롤 없는 전용 창에서 8방향 버튼, 대기·좌우 잡힘·작업 중·작업 완료와 중지를 한 번에 표시합니다. 이동은 2초 동안 60pt 진행하며 대각선도 같은 속도입니다. 가장자리에서는 이동 공간을 확보한 뒤 시작합니다. 대기·잡힘은 2초, 작업 중은 상단 바와 함께 6초, 완료는 전체 모션을 한 번 재생합니다. 중지·직접 드래그·창 닫기·디버그 모드 끄기로 테스트를 종료할 수 있습니다. 실제 작업과 크레딧은 바뀌지 않고 시스템 알림도 보내지 않습니다.
- 기본 100% 토끼는 초기 버전의 70%와 같은 크기입니다. 기존 70% 설정은 100%로 자동 변환됩니다. 말풍선은 토끼 배율과 무관하게 14pt 글씨를 유지합니다.
- 작업 유무와 관계없이 **5초 주기**로 작업을 확인합니다. 한 조회가 오래 걸리면 중첩하지 않으며 서버 응답 시간에 따라 반영이 더 늦어질 수 있습니다. 크레딧은 **60초마다** 확인하고, 작업 ID·상태가 바뀌면 즉시 확인한 뒤 15초 동안 후속 조회로 정산 반영을 확인합니다. 작업 수가 같아도 작업 교체·완료를 구분합니다.
- 크레딧 조회만 실패하면 확인된 작업 상태와 완료 알림은 갱신하고, 크레딧은 마지막 확인값과 **갱신 지연** 표시를 유지합니다. 상세 현황 하단에서 작업/크레딧 확인 시각을 따로 볼 수 있으며 크레딧 숫자 툴팁에도 확인 시각을 표시합니다. 수동 새로고침은 두 정보를 함께 확인합니다.
- 조회 오류 시 최대 5분까지 재시도 간격을 늘리고 서버의 `Retry-After`를 따릅니다. 오프라인/잠자기는 조회를 중지하고 연결 복구/깨어남 때 다시 확인합니다. 지크 숨김은 데이터 조회를 중지하지 않습니다.
- 대기 모션은 12fps, 산책·드래그·작업 중·완료는 최대 24fps입니다. 마우스 이동 이벤트로 클릭 영역을 갱신하며 산책 이동 중에만 20Hz 이동 타이머를 사용합니다. 산책 대기 중에는 1Hz, 산책 비활성화 시에는 이동 타이머를 멈춥니다. 이벤트 감지가 불가능한 경우 낮은 빈도의 위치 확인으로 대체합니다.
- 지크 카드·상단 바 열기와 수동 갱신은 하나의 조회 일정으로 합칩니다. 정상 5초, 오류/서버 대기를 공유하고 신선한 잔액은 창 열기만으로 강제 조회하지 않습니다.
- 로그인 준비·네트워크 복구·잠자기 복귀 시 0~1초 안에서 시작을 분산합니다. 웹 응답이 멈추면 네이티브 25초 제한으로 대기를 해제하고 웹 세션을 다시 로드합니다.
- 모니터가 분리돼 토끼 전체가 보이지 않을 때만 위치 복구. 일부가 화면 밖에 있는 배치는 유지합니다. Reduce Motion 지원. 동작 줄이기나 잠자기 중에는 메뉴 막대 달리기도 멈춥니다.

## 개발

macOS 14 이상, Swift 6 이상/Xcode 필요. 외부 라이브러리 의존성은 없습니다. JS 회귀 테스트에는 Node.js 20 이상이 필요합니다.

```sh
bash scripts/build.sh
bash scripts/test.sh
```

`build.sh`는 Release 실행 파일, 리소스, 아이콘과 개인정보 매니페스트를 `dist/ZCRE 서포터.app`에 묶습니다. 기본값은 현재 CPU용 ad hoc 서명이며 Hardened Runtime을 켭니다. 실행 중인 앱은 교체하지 않습니다. `ARCHS=universal`은 Apple Silicon·Intel 공용 앱을 만듭니다.

```sh
# 앱을 종료한 뒤 실행. 기능 테스트를 실행하지 않습니다.
bash scripts/release.sh --local
```

공용 ZIP·SHA-256·릴리스 메타데이터를 생성합니다. Developer ID 서명과 공증은 [배포 안내](docs/RELEASE.md)의 별도 절차로 진행합니다. 패키징 도구는 Xcode와 Python 3을 사용합니다.

개발용 실행 인자:

```sh
open "dist/ZCRE 서포터.app" --args --demo --show-dashboard
```

개발 환경에서 메뉴 막대 앱을 인식하지 못하는 UI 도구를 위해 `--demo --inspect-ui`는 현황판을 일반 창으로 표시합니다. `--show-dashboard`는 현황판을 바로 엽니다. `--demo --smoke-test`는 토끼 창/메뉴 막대 생성 후 결과를 출력하고 종료합니다. `--smoke-test`만 사용하면 ZCRE 웹의 초기 로딩도 검사합니다. 미리보기와 스모크 검사는 알림 권한을 요청하지 않습니다. `--render-preview docs/preview.png`는 개인 데이터 없이 앱 UI 이미지를 렌더링합니다.

## 연결과 개인정보

앱 소유의 `WKWebView`에서 사용자가 ZCRE에 직접 로그인합니다. 웹 자체의 Clerk 세션 갱신을 사용하며, 세션 토큰은 웹 페이지 내부에서 ZCRE의 동일 출처 요청에만 사용됩니다. 네이티브 코드로 토큰을 전달하거나 Codex/브라우저의 쿠키를 복사하지 않습니다. 웹 세션의 저장소는 WebKit이 관리합니다. 연결 해제는 이 앱의 웹 데이터를 지웁니다.

네이티브 화면으로 전달하는 정보는 워크스페이스 식별자·이름, 크레딧 3종, 작업 ID·모델·종류·상태·생성 시각, 웹 화면의 동시 생성 사용량/한도입니다. 전달된 웹 사용량은 표시하지 않고 API 작업 목록에서 다시 계산합니다. 상태 감시에는 프롬프트·결과 URL·결제 내역을 전달하지 않습니다. 사용자가 결과 창을 열면 HTTPS 미디어 URL을 네이티브 메모리에서 처리하며, 재생·저장은 사용자 조작으로 수행합니다. 현재 작업 데이터는 메모리에 두고, 최근 알림 30개의 표시 문구·시각·읽음 상태·기록 출처를 앱 전용 Application Support 폴더에 저장합니다. 계정/작업 구분에는 원본 ID 대신 SHA-256 해시를 저장하며, 같은 계정을 확인하기 전에는 복원하지 않습니다. 사용자 설정과 토끼 위치는 UserDefaults에 저장합니다. 통계 수집/별도 서버 전송은 없습니다.

읽는 경로는 ZCRE 공개 웹 클라이언트에서 확인한 `GET /api/v1/billing/balance`, `GET /api/v1/requests`, `GET /api/v1/requests/{id}`입니다. 생성·결제·자동 충전 요청을 구현하지 않았습니다. 서비스 상태는 별도로 `GET /api/public/service-status?window=24h`를 읽습니다. 계정 쿠키·토큰을 붙이지 않는 임시 네트워크 세션을 사용하며 상태 응답은 메모리에만 보관합니다.

동시 생성 한도는 앱 소유 웹 화면의 `동시 생성 한도:` 접근성 레이블에서 읽습니다. 해당 레이블의 사용량은 오래된 값일 수 있으므로 사용하지 않습니다. 화면 구조가 바뀌거나 레이블이 없으면 한도를 추측하지 않고 진행 작업 수만 보여줍니다.

## 현재 제약

- 독립 앱에서 한 번 로그인해야 합니다. 제3자 로그인 제공자가 내장 웹 로그인을 제한한다면 지원되는 ZCRE 로그인 방식이 필요합니다. 이 Mac에서는 로그인된 웹의 잔액과 앱 현황판 잔액을 대조했습니다.
- 개인 크레딧 워크스페이스용입니다. Unit 기반 조직 계정은 크레딧으로 오표시하지 않고 안내합니다.
- 최초 연결 시 최대 1,000개 기록을 확인합니다. 이를 넘으면 현황판에 범위를 표시합니다. 이후에는 평소 20개, 최근 기록이 많은 경우 50개 단위로 필요한 페이지만 읽고, 목록에서 빠진 미완료 작업은 개별 확인합니다. 조회 구간을 60초 겹쳐 늦게 노출된 기록도 확인하며 최근 완료 기록 50개와 모든 미완료 작업은 메모리에서 재사용합니다.
- 폴링 방식이므로 실시간 푸시가 아니며, 앱 종료/잠자기 중 알림은 제공하지 않습니다. macOS 집중 모드·알림 설정에 따라 시스템 배너 표시가 달라집니다.
- ZCRE 웹 내부 조회 경로와 응답 형식이 바뀌면 어댑터 갱신이 필요합니다. 오류를 0 크레딧이나 작업 완료로 취급하지 않습니다.
- 현재 산출물은 로컬 ad hoc 서명이며 공증된 배포판이 아닙니다. 자동 업데이트는 구현하지 않았으며 검증된 새 앱을 수동 교체합니다. 로그인 시 자동 실행은 구현했으며 실제 등록 동작은 수동 확인 대상입니다.
- 0.2.20 출시 준비 점검에서 Swift 회귀 102개와 JavaScript 브리지 43개, 배포 프로파일 검사 5개까지 총 150개가 통과했습니다. 실제 서버 생성·완료, 스피커 청취, 실제 로그인 상태를 동반한 종단 간 검증을 수행한 결과는 아닙니다. 효과음 상태 전이는 실제 소리를 내지 않는 재생 대역으로 검사했습니다.

상세 기획은 [docs/PRODUCT.md](docs/PRODUCT.md), 검증 기록은 [최적화 검증](docs/OPTIMIZATION-0.2.9.md)를 확인하세요.

0.2.6의 조회 정책과 짧은 CPU 관찰 결과는 [자원 사용 기록](docs/RESOURCE-USAGE-0.2.6.md)에 있습니다.

소스의 기능·함수별 한국어 설명은 [코드 안내](docs/CODE-GUIDE-KO.md), 서비스 요청 부하와 남은 개선점은 [서비스 영향 재검토](docs/SERVICE-IMPACT-REVIEW-2026-10-26.md)를 참고하세요.

0.2.9의 변경·요청 수 비교는 [최적화 기록](docs/OPTIMIZATION-0.2.9.md), 좌우 작업·실패 모션과 오디오 변경은 [모션·오디오 기록](docs/MOTION-AUDIO-0.2.9.md)에 있습니다.

### 0.2.11 · 진행 중 작업과 결과 보기
상단 바 현황판 왼쪽에서 진행 중 작업을 확인하고, 완료 알림을 눌러 결과를 미리 보거나 저장할 수 있습니다. 영상·오디오는 재생 버튼을 눌러야 불러옵니다. 기존 작업 조회 주기는 유지합니다. 자원 제한과 오래된 알림의 처리 방식은 [결과 보기 안내](docs/RESULTS-0.2.11.md)를 참고하세요.

### 0.2.12 · 지크 원형 메뉴
지크를 누르면 이미지·영상·현황·설정 원형 메뉴가 열립니다. 이미지/영상 도구는 공식 ZCRE 페이지로 연결하며 파일 드롭이나 자동 생성을 하지 않습니다. [메뉴 안내](docs/QUICK-MENU-0.2.12.md)

### 0.2.13 · 중앙이 빈 원형 메뉴
지크를 누르면 간단 현황과 이미지·영상 메뉴가 함께 나타납니다. 지크와 작업 중 문구는 중앙에 그대로 보이며, 설정은 상단 바나 우클릭 메뉴에서 열 수 있습니다. [배치 안내](docs/QUICK-MENU-0.2.13.md)
