# App Review notes — draft for the submitted build

ZCRE Supporter is a macOS menu bar and desktop companion for an existing ZCRE account. It displays credit balance, running jobs, completion/failure notifications and public service health. It provides native companion animations, result preview and user-initiated saving. Tool shortcuts open ZCRE web pages. It does not execute AI generation locally.

The app uses LSUIElement and may not appear in the Dock. After launch, look for the Zic icon in the macOS menu bar and the desktop character. Click the menu bar icon for the full status panel; click the character for the compact status and tool menu. Character visibility can be restored from the menu bar.

Suggested steps
1. Launch and open the account connection window, then sign in using the review account.
2. Click the character and inspect credits and tool categories. Image/video tools open the service pages.
3. Open the menu bar panel. Inspect running jobs, recent alerts and service health.
4. Open a completed job from recent alerts or the detail window. Press play for video/audio; use Download and choose a file destination.
5. Hide/show Zic from the menu bar. Open settings and adjust sound/roaming/notifications.
6. Disconnect the account in settings. Account monitoring and the app's local account history are cleared; the service account is not deleted.

Current build includes a diagnostic motion menu in Settings → Debug mode. Activation code: zcrenext. It simulates character states without creating billable jobs; it resets on restart. This feature must be disclosed if retained in the submitted build. If removed for release, update these notes accordingly.

Notification permission is optional. macOS notification delivery depends on user settings. Login at launch is optional.
