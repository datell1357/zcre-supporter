# ZCRE 서포터 Mac App Store 사전 준비 자료

2026-10-26 / 현재 앱 0.2.20 (23) / 자료 초안, 아직 제출하지 않음

- metadata: 한국어 소개/부제/키워드/첫 출시 문구와 입력값
- legal: 개인정보 처리방침 초안 및 App Privacy 확인표
- review: 영문 심사 노트, 지원 페이지 초안, 제출 전 기술·운영 체크리스트
- assets/screenshots: 실제 앱 촬영본에서 만든 1440×900 PNG 후보 5장
- assets/preview: 30초 이내 1080p 스토어 프리뷰 후보
- assets/icon: 기존 앱 1024px 아이콘 후보
- tools: 재현 가능한 미디어 준비 스크립트

[확정 필요] 및 [REQUIRED] 필드는 임의로 채우지 않았다. 계정 암호/토큰은 포함하지 않는다. 개발자 등록, 약관 동의, Apple 제출과 웹 게시를 실행하지 않았다.

현재 홍보영상 v9는 46.5초여서 스토어 프리뷰 길이 제한에 맞지 않는다. 별도 짧은 후보를 준비했다. 스크린샷은 실제 앱 녹화에서 추출해 규격 캔버스에 배치했으며 실시간 계정 수치는 촬영 당시 값이다. 브랜드/캐릭터 사용 승인은 사용자 확인을 받았다. 증빙 범위를 보관하고 최종 빌드 UI를 대조한 후 사용한다. 기존 업스케일 예시 영상의 폭력 묘사와 콘텐츠 권리 검토가 필요하므로 스토어 후보에는 해당 결과 영상을 넣지 않았다.

우선 확정할 정보: 판매자 개인/조직 명의, 지원 연락처, 정책 게시 주소, 앱 가격, 심사 계정. 나머지 코드 과제는 review/release-gates.md 참고.
