# App Privacy 입력 검토표

현재 PrivacyInfo.xcprivacy의 collectedDataTypes 빈 배열은 App Store Connect에서 '수집 없음'을 선택할 근거가 아니다. 고정 ZCRE WebKit 화면의 서비스 수집을 포함해 확인한다. 서버 사업자에게 아래 표를 확인받기 전 최종 선택 금지.

| 데이터 | 앱에서 확인한 처리 | 서버 확인 및 제출 판단 |
|---|---|---|
| 계정 ID/이메일 | 로그인 웹 세션 및 계정 구분 | ZCRE/인증 제공자 수집, 계정 연결 여부, 보유 기간 확인 |
| 크레딧/이용 이력 | 잔액·작업 상태 조회 | 구매 이력/제품 상호작용 해당 여부 및 서버 저장 확인 |
| 사용자 콘텐츠 | 결과 이미지·영상·오디오 미리보기 및 저장 | 웹 생성 기능의 입력·출력·프롬프트 수집도 포함해 확인 |
| IP/진단/기기 정보 | HTTPS 접속, 별도 네이티브 분석 SDK 없음 | 웹 분석·로그·CDN 수집 확인 |
| 설정/로컬 알림 | 기기에 저장, 앱 자동 업로드 없음 | 기기 밖 전송되지 않는 정보와 서버 데이터를 구분 |
| 추적 | 네이티브 매니페스트 false | 웹 광고/교차 서비스 추적 여부 확인 후 최종 답변 |

목적 후보는 앱 기능 제공이며, 광고/분석 목적은 추측으로 선택하지 않는다. 연결 여부와 보유 기간은 서비스 운영자 확인을 받는다. Required Reason API 선언과 개인정보 라벨은 서로 다른 제출 항목이다.

참고: https://developer.apple.com/app-store/app-privacy-details/
