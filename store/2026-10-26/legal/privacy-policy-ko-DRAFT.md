# ZCRE 서포터 개인정보 처리방침 초안

공개 전 확정 필요: 운영자 [운영자명], 연락처 [지원 이메일], 시행일 [YYYY-MM-DD], 공개 주소 [HTTPS URL]. 아래 내용은 0.2.20 소스 검토 기준이며 ZCRE 및 로그인 제공자의 실제 데이터 처리 관행 확인 후 확정해야 합니다.

## 처리 목적과 정보
ZCRE 서포터는 사용자가 연결한 ZCRE 계정의 크레딧, 작업과 결과, 서비스 상태를 표시합니다. 로그인은 앱 전용 WebKit 창에서 이루어집니다. 쿠키와 웹 저장소는 WebKit이 관리하며, 일반 브라우저의 로그인 정보를 복사하지 않습니다.

계정·워크스페이스 구분값, 크레딧, 작업 식별자·종류·모델·상태·시각 및 동시 생성 한도를 표시합니다. 작업 결과를 열면 결과 메타데이터와 HTTPS 미디어 주소를 가져옵니다. 영상·오디오는 사용자가 재생을 선택할 때 불러오며, 다운로드는 사용자가 지정한 위치에 저장합니다. 결과 주소와 인증 토큰을 로컬 알림 이력에 저장하지 않습니다.

## 기기 내 보관
설정은 UserDefaults에 저장합니다. 작업 종류별 알림 선택과 앱 자체 집중 모드의 시작·종료 시각도 기기에 저장하며 macOS 집중 상태는 읽지 않습니다. 최근 알림은 최대 30개의 문구·시각·내부 읽음 상태와 계정/작업 구분용 해시를 로컬 파일에 저장합니다. 알림에는 작업 종류·모델·시작 시각이나 잔액 부족 정보가 포함될 수 있습니다. macOS 알림 센터에도 알림이 남을 수 있습니다. 결과 조회 캐시와 이미지 캐시는 메모리에서 제한적으로 사용합니다. 사용자가 다운로드한 결과 파일은 사용자가 삭제할 때까지 해당 저장 위치에 남습니다.

## 외부 통신
로그인과 현황 조회를 위해 ZCRE 및 로그인 제공자와 통신합니다. 결과 재생·저장 시 ZCRE가 제공한 미디어 전달 서버와 통신하며, 해당 서버는 IP 주소 등 통신 정보를 처리할 수 있습니다. 공개 서비스 상태 조회에는 계정 인증정보를 붙이지 않습니다. 웹 서비스 내 수집 항목, 처리 주체, 보유 기간과 국외 이전 사항은 서비스 운영자의 확인을 받아 공개 문서에 추가해야 합니다.

검토한 네이티브 소스에는 별도 광고·분석 SDK나 자체 분석 서버로 자동 전송하는 경로가 없습니다. 이는 WebKit 안에서 이용하는 웹 서비스까지 개인정보를 수집하지 않는다는 뜻은 아닙니다.

## 사용자 제어
설정의 계정 연결 해제는 앱의 WebKit 데이터와 로컬 계정 알림 이력을 삭제하고 감시를 중지합니다. ZCRE 서버의 계정·작업·결과와 이미 다운로드한 파일은 삭제하지 않습니다. 최근 알림 전체 지우기는 로컬 이력을 비웁니다. 지크 숨김은 데이터 감시 중단이나 삭제 기능이 아닙니다. 시스템 알림·자동 실행과 앱의 효과음·알림은 사용자가 설정할 수 있습니다.

마우스 위치는 캐릭터 이동 반응에 사용하며 저장·전송하지 않습니다. 다른 앱의 오디오 사용 여부는 타자음 간섭 방지에 사용하며 오디오 내용을 녹음하지 않습니다. 사용자가 진단을 내보내면 제한된 앱 상태 정보가 로컬 파일로 저장되며 앱이 자동으로 전송하지 않습니다.
