# 크리에이터 탭 · macOS 개발본

상단 바 현황판에서 `작업 / 크리에이터`를 선택한다. 기본 탭은 작업이며, 기존 작업·크레딧 감시 스케줄은 변경하지 않는다. 이 변경은 개발본 구현이며 기존 App Store 제출본이나 GitHub 설치 파일을 자동 교체하지 않는다.

## 최소 데이터 경로

- 기존 앱 전용 WebKit 로그인 세션에서 `GET /api/v1/zcre-next/metrics` 한 번 호출하고, 채널별 `GET /api/v1/zcre-next/metrics/accounts/{id}?range=30d`를 순차 호출한다. HTML·DOM·페이지 전체를 읽거나 파싱하지 않는다.
- 토큰은 WebKit 내부에 유지한다. 네이티브에는 합계·7일 증감·수집 시각·일시 중지 여부와 채널별 플랫폼·핸들·팔로워/구독자·7일 증감·수집 시각·수집 상태·증감 제공 여부 및 최대 32개의 일별 날짜·팔로워 수만 전달한다.
- 내부 계정 ID, 인증 코드, 계정 등록 정보, 게시물·썸네일·참여율·미션은 전달하지 않는다. 추이 응답에서는 날짜와 팔로워 수만 추출한다. 벤치마크/미션 API와 미디어 요청은 추가하지 않는다. 더 자세한 정보는 공식 웹 페이지로 연결한다.
- API 응답이 필드 선택을 지원하는지 확인되지 않아 요약 JSON 자체는 서비스에서 제공하는 형태로 수신한다. WebKit에서 허용한 필드만 새 객체로 구성해 네이티브로 전달한다. 서버 응답은 최대 256KiB, 네이티브 전달은 최대 96KiB와 32개 채널로 제한한다.

## 요청·계정 경계

- 탭을 열 때만 조회하고 성공 후 10분간 메모리 캐시를 재사용한다. 상시 타이머·폴링이나 디스크 저장은 없다.
- 요청 중 재클릭은 하나의 요청으로 합친다. 실패 후 최소 60초와 서버 Retry-After를 유지하며 다시 열기/새로고침으로 우회하지 않는다.
- 탭/팝오버 닫기·오프라인·잠자기 시 진행 중 요청을 중단한다. 계정·워크스페이스·데모 전환 시 캐시를 비우고 늦게 도착한 이전 응답을 폐기한다.
- 요청 전·토큰 발급 후·응답 후 사용자·로그인 세션·조직이 일치하는지 WebKit에서 확인한다. 데모 모드에서는 실제 메트릭 API를 호출하지 않는다.

## 표시 기준

웹의 요약 합계를 사용한다. 7일 변화에서 YouTube 제외를 명시하고, 없는 값은 0으로 바꾸지 않고 `—`로 표시한다. YouTube/파생 지표 미제공 채널은 `제공 안 됨`, 오류 후 보존 값은 이전 값으로 안내한다. 계정 미연결·채널 미등록·오프라인·이용 권한 부족도 별도로 안내한다.

검증: `bash scripts/test.sh`. JavaScript 응답 허용 목록/계정 경계/HTML·크기 제한/429, Swift 캐시/중복 요청/계정 전환/숨김 시 늦은 응답 차단을 포함한다. 테스트는 합성 데이터만 사용한다.

## 그래프 배치

연결 채널을 2열 그래프로 배치하며 네 채널은 2×2로 스크롤 없이 표시한다. 수치는 작게, 남은 창 높이는 그래프에 배정한다. 실제 수집점만 선과 점으로 표시하고 누락 날짜를 0이나 임의 값으로 채우지 않는다. 잘못된 날짜·중복 날짜·계정 불일치 추이는 표시하지 않는다. 추이 조회 실패는 현재 수치와 별도로 안내한다. 네 채널일 때 캐시 만료 후 탭 열기에만 요약 1회+추이 4회 GET, 캐시 중 추가 요청은 없다. 서버 API의 필드 선택 지원이 확인되지 않아 JSON 응답의 게시물 필드는 WebKit에서 폐기하며 네이티브로 전달하지 않는다.
