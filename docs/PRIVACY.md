# ZCRE 서포터 개인정보 처리 범위

앱은 사용자가 ZCRE에 로그인한 앱 전용 WebKit 세션에서 크레딧과 작업 현황을 조회한다. 로그인·서비스 이용에는 ZCRE와 로그인 제공자의 정책이 적용된다. 앱의 네이티브 부분은 별도 분석 서버, 광고 추적 또는 자동 진단 업로드를 사용하지 않는다.

## 보관 및 전송

- 인증 쿠키와 웹 저장소는 WebKit이 앱 단위로 관리한다. 다른 브라우저나 Codex의 로그인 정보를 복사하지 않는다. 토큰은 네이티브 코드·로그·진단 파일로 전달하지 않는다.
- 크레딧, 작업 ID·모델·종류·상태·시각, 워크스페이스 식별자·이름, 동시 생성 한도는 조회 후 메모리에서 표시한다. 동시 생성 진행 개수는 최신 API 작업에서 계산하며 웹 화면의 오래된 사용량은 사용하지 않는다. 상태 조회에서는 프롬프트와 결과 URL을 네이티브로 가져오지 않는다. 사용자가 결과 창을 열면 결과 메타데이터와 HTTPS 미디어 URL을 네이티브로 전달하며, 주소는 메모리에서 제한적으로 캐시하고 로컬 알림 파일·로그에는 저장하지 않는다. 영상·오디오는 재생을 선택할 때 불러오고 다운로드는 사용자가 지정한 위치에 저장한다. 계정 연결 해제는 이미 다운로드한 파일을 삭제하지 않는다.
- 최근 알림 30개의 표시 문구(모델·작업 종류·시작 시각 또는 크레딧 부족 시 잔액 포함)·시각·읽음 상태·기록 출처를 `~/Library/Application Support/kr.co.zcre.bunny.prototype/RecentAlerts.json`에 로컬 보관한다. 계정/작업 구분값은 SHA-256 해시이며 원본 ID는 저장하지 않는다. 파일 권한은 사용자 읽기/쓰기(0600)다. 재실행 후 같은 계정을 확인해야 복원하며 계정이 바뀌면 현재 계정의 기록으로 교체한다. 인증 확인 중에는 목록을 숨기고 미리보기 기록은 저장하지 않는다. macOS 알림은 OS 알림 센터에 남을 수 있고 계정 알림 초기화 시 이 앱의 전달/대기 알림도 제거한다.
- 서비스 상태는 공개 `https://www.zcre.co.kr/api/public/service-status?window=24h`에 별도 GET으로 조회한다. 쿠키·인증 토큰·사용자 작업 정보는 붙이지 않으며 응답은 메모리에만 둔다. 현황판이 열린 동안 1분마다 조회하고 닫기·잠자기 때는 중지한다.
- 네트워크 연결 여부는 조회 중지/재개에만 사용한다. 마우스 이동 이벤트·위치는 지크의 클릭 영역과 이동 반응에만 사용하며 저장·전송하지 않는다.
- 타자음이 다른 앱 소리·통화를 방해하지 않도록 CoreAudio의 프로세스별 입력/출력 실행 여부를 확인한다. 오디오 내용·앱 이름은 읽지 않으며 녹음·오디오 탭·마이크 권한 요청·기기 설정 변경은 하지 않는다. 프로세스 식별값은 자기 앱을 제외하는 데만 쓰고 저장·전송하지 않는다. 지원하지 않는 macOS에서는 출력 장치 사용 여부만 확인하고, 조회 실패 시 타자음을 쉰다.
- 캐릭터 표시·크기·위치와 알림 설정은 UserDefaults에 저장한다. 로그인 항목은 사용자가 켜는 경우 macOS ServiceManagement에 등록한다.
- 진단 내보내기는 사용자가 선택한 로컬 JSON 파일에 앱/OS 버전, 연결 상태, 개수와 설정만 저장한다. 계정 식별자·잔액·작업 내용·URL·토큰을 제외한다. 파일 전송은 앱이 수행하지 않는다.
- 앱의 조회는 허용된 ZCRE HTTPS GET 경로만 사용한다. 생성·결제·충전 기능은 없다. 로그인 페이지의 웹 동작과 계정 로그아웃은 사용자가 직접 제어한다.

## 삭제 및 제어

**설정 → 계정 → 연결 해제**는 이 앱의 WebKit 데이터를 지우고 감시와 현재 알림, 로컬 알림 파일을 삭제한다. **최근 알림 → 전체 지우기**는 목록을 비우고 삭제 시점을 저장해 이전에 시작된 과거 작업이 자동으로 재등장하지 않게 한다. ZCRE 계정 자체나 서버의 작업 기록을 삭제하지 않는다. 지크 숨김은 데이터 삭제가 아니며 상단 바 감시는 계속된다. 알림 종류·배너·소리는 설정에서, macOS 알림과 자동 실행 승인은 시스템 설정에서 제어한다.

배포 번들의 `PrivacyInfo.xcprivacy`에는 앱 내부 설정 사용을 위한 UserDefaults `CA92.1`, 경과 시간과 타이머 계산을 위한 SystemBootTime `35F9.1`을 기재한다. 이 매니페스트는 배포 주체가 확정할 공개 개인정보 고지와 연락처를 대신하지 않는다.

## 0.2.17 알림 설정

작업 종류별 알림 선택, 즉시 집중 여부와 매일 집중 시작·종료 시각(시·분)을 UserDefaults에 로컬 저장한다. macOS 집중 상태를 읽거나 전송하지 않는다. 집중 모드와 작업 알림 필터는 서버 조회량을 늘리지 않으며 기존 기록 보관·삭제 정책을 유지한다.
