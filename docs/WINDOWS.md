# Windows 버전 구현 계획

현재 저장소는 macOS 앱이며 Windows 실행 파일은 아직 제공하지 않습니다.

## 재사용과 별도 구현

- 재사용: 지크 스프라이트·효과음, 웹 조회 JavaScript, 모의 서버 응답 회귀 사례.
- 이식: Swift 상태 전이·갱신 정책·알림 중복 방지·좌표 계산.
- 별도 구현: 투명 데스크톱 창, 작업 표시줄 트레이, 로그인 세션, Windows 알림, 자동 시작, 다운로드, 잠자기·네트워크 복귀, 오디오 공존 처리.
- 기본 지원 대상으로 Windows 11 x64를 제안하며 ARM64는 별도 검증 후 추가합니다.
- 구현 프레임워크는 WebView2 로그인·투명 창·트레이의 작은 실행 시제품으로 검증한 뒤 확정합니다.

## 출시 판정 기준

- 실제 계정에서 작업 시작·진행·완료·실패와 크레딧 정산을 대조합니다.
- 병렬 작업, 취소, 재접속, 계정 전환, 세션 만료 및 서버 제한 응답을 검증합니다.
- 네트워크 오류를 작업 실패로 간주하지 않고 마지막 확인 시각과 갱신 지연을 표시합니다.
- 숨김 상태에서도 데이터 갱신은 유지하며 모션·효과음만 중단합니다.
- 중복 알림·요청 중첩·다중 실행을 방지하고 5초 작업 / 60초 크레딧 정책을 검증합니다.
- DPI 100/125/150/200%, 다중 모니터, 화면 가장자리와 절전 복귀를 확인합니다.
- 다른 앱의 소리·통화를 방해하지 않는지 실제 Windows에서 확인합니다.
- 새 사용자 설치와 기존 버전 업데이트, 종료·제거 및 장시간 실행을 검증합니다.

버그가 전혀 없다는 보장은 하지 않습니다. 자동 검사 통과와 실제 Windows에서의 동작 확인을 구분하고, 미검증 항목이 남아 있으면 정식 배포로 표시하지 않습니다.
