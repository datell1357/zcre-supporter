# 0.2.19 원형 메뉴 밀착 배치

이전 배치는 작업 문구용 170pt 보호 폭을 지크 전체 높이에 적용해 원이 크게 유지됐다.
몸과 작업 문구의 보호 영역을 분리하고 버튼이 충돌하지 않는 최소 반지름을 계산한다.
기본 크기의 홈 반지름은 약 133pt에서 116pt 이하로 줄며 지크 크기에 맞춰 달라진다.
버튼 56pt와 홈 메뉴 60도 간격은 유지한다. 긴 작업·디버그 문구는 실제 글꼴 폭을 측정해 보호한다.

검증: Swift 레이아웃 테스트 6개와 메뉴 관련 XCTest 5개 통과. 크기 70/100/150%, 화면 가장자리,
다중 모니터 음수 좌표, 긴 문구 110/170/240pt, 버튼 겹침, 등간격 배치를 확인했다.
