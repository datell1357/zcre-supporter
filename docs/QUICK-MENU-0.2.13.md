# 지크를 가리지 않는 원형 메뉴 · 0.2.13

- 지크 클릭 한 번에 위쪽 간단 현황과 중앙이 빈 원형 메뉴를 함께 표시
- 원형 메뉴의 설정·별도 현황 버튼 제거. 이미지·영상·닫기만 바깥에 배치
- 설정은 기존 상단 바 또는 지크 우클릭 메뉴에서 접근
- 이미지/영상 하위 메뉴도 중앙을 비워 지크와 작업 문구를 유지. 뒤로·닫기도 바깥에 표시
- 현황 카드와 각 버튼을 별도의 작은 투명 창으로 구성. 테두리 장식은 마우스 이벤트를 받지 않으므로 중앙의 지크 클릭·드래그가 펫 창에 전달됨
- 지크 아래 42pt와 최소 180pt 너비를 보호해 작업 중 문구와 버튼이 겹치지 않음
- 화면 끝에서는 지크 위치를 제한하지 않고 현황·버튼만 여유 공간으로 재배치. 위 공간이 없으면 현황도 다른 방향으로 배치
- 메뉴 클릭 토글과 실제 드래그를 구분해 클릭 시작 시 메뉴가 불필요하게 닫혔다 다시 열리는 문제 방지
- 추가 폴링·업로드·생성 요청 없음

## 검증
기존 테스트 135개와 새 배치 테스트 2개 통과
2개 화면 좌표계(음수 좌표 포함), 크기 70/100/150%, 모서리·중앙 위치, 기본/이미지/영상 메뉴 조합 162개에서 화면 경계·지크/작업 문구·현황·다른 버튼과의 겹침 및 버튼 누락 없음 확인
