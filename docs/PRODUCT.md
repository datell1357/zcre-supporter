# ZCRE 서포터 제품 기획 · 0.2

## 목적

이미지·영상을 만드는 동안 브라우저를 계속 확인하지 않아도, 사용 가능한 크레딧과 작업 완료를 곁에서 알려주는 작은 맥 앱.

## 핵심 경험

1. 실행하면 검정 니트 비니를 쓴 흰 지크와 메뉴 막대 아이콘이 나타난다.
2. 토끼/메뉴 막대를 눌러 로그인하거나 가상 데이터로 미리보기 한다.
3. 연결 후 메뉴 막대에는 사용 가능 크레딧 숫자를 표시한다. 대기/생성 중 작업이 있으면 지크가 네 발로 달리는 모션을 표시하고, 없으면 정지 아이콘으로 돌아온다. 동작 줄이기/잠자기 상태에서는 애니메이션을 멈춘다.
4. 토끼 클릭 시 232×104pt 카드에 현재 크레딧, 이미지/영상 동시 생성 사용량과 한도, 합산만 표시한다. 현재 모니터의 화면 공간과 실제 토끼 영역으로 위·아래·좌우 중 방향을 정한다. 메뉴 막대에서는 크레딧·작업 개수·최신 알림 10개와 지크 숨김/표시를 제공한다. 상세 현황은 보관된 전체 알림(최대 30개)을 표시한다.
5. 생성 중에는 지크 아래에 진행 중인 작업 수를 표시하고 산책을 멈춘다. 불타오르며 컴퓨터를 두드리는 자세는 모니터 중앙을 향한다. 지크가 오른쪽에 있으면 왼쪽, 왼쪽에 있으면 오른쪽을 바라보도록 같은 원본을 반전한다. 서버에서 확인하지 않은 진행률은 만들지 않는다.
6. 완료되면 산책을 잠시 멈추고 활짝 웃으며 연속으로 뛰는 약 2.7초 모션을 한 번 재생하며 말풍선을 띄운다. 허용된 경우 macOS 알림도 보낸다. 시스템 알림 클릭은 앱의 알림 목록을 열고, 목록의 항목은 ZCRE 생성 기록 또는 크레딧 화면으로 이동한다.
7. 지크를 숨겨도 조회는 계속된다. 완료·실패·크레딧 부족은 상단 바 아래의 비활성 배너로 표시한다. 상단 바에는 지크 아이콘과 크레딧만 표시하고 미확인 알림 숫자는 붙이지 않는다. 배너는 8초 후 닫히고 최근 30개 알림은 이 Mac에 저장한다. 같은 계정 확인 후 복원하고, 계정 변경 시 교체하며 연결 해제 시 삭제한다. 미리보기는 실계정 기록을 숨기고 별도 메모리 목록만 사용한다. 알림 종류 설정을 따르며 상단 바 배너만 별도로 끌 수 있다.
8. 로그인 시 자동 실행은 사용자가 설정에서 직접 켠다. 첫 실행 안내 이후 시작은 상단 바에서 조용히 이뤄진다. 다시 열기와 명시적인 실행 인자로 현황판/계정 창을 연다.
9. 실제 작업 실패 시 털썩 앉아 양손으로 눈을 비비고 눈물을 옆으로 흘리는 약 5초 모션을 한 번 재생한다. 과거 이력·조회 오류는 울음 이벤트로 처리하지 않으며 실패 알림 설정을 따른다.
10. 붙잡힘 효과음과 작업 중 짧은 타자음을 설정에서 켜고 음량을 조절한다. 타자는 약 1초 재생 후 5초 쉬며 다른 앱 소리·통화가 감지되면 중단한다. 오디오 캡처나 시스템 음량 변경은 없다.

## 디자인

- 캐릭터: 사용자 제공 시트의 흰 털, 검정 비니, 분홍 귀 안쪽과 코, 시크한 표정. Grok과 sprite-gen으로 생성·투명화·반복 추출·검수했다. 대기/드래그/완료 각 64프레임, 방향별 산책 각 29프레임이다. 정면·뒷면·옆면·앞/뒤 대각선의 다섯 원본과 좌우 반전으로 8방향을 표현한다.
- 현황판·설정·말풍선: ZCRE 웹의 검정 배경, 차콜 카드, 얇은 테두리, 흰 주요 버튼과 초록 상태 표시. macOS 기본 글꼴과 숫자 고정폭 사용.
- 토끼가 다른 앱의 키보드 포커스를 가져오지 않도록 비활성 투명 NSPanel 사용.
- 투명 영역은 마우스 이벤트를 통과시키고 실제 토끼/말풍선 영역만 상호작용.
- 산책은 상하좌우·대각선의 8방향, 40–210pt 거리, 7–16초 휴식을 무작위로 선택한다. 대각선도 같은 속도로 이동한다. 마우스를 올리거나 현황 카드를 열면 정지한다.
- 토끼 기본 100%는 최초 프로토타입의 70%와 동일하다. 말풍선은 14pt 글씨/252pt 폭으로 별도 배치하며 토끼 배율의 영향을 받지 않는다.
- 드래그는 네이티브 마우스 이벤트와 화면 좌표를 사용한다. 4pt 이상 움직이면 옆모습의 놀란 표정/버둥거림을 재생하고 뒤쪽 목덜미 기준점을 커서에 고정한다. 움직인 창의 좌표를 다시 이동량에 더하지 않는다.
- 수동 배치는 화면 가장자리/투명 여백에 제한하지 않는다. 드래그 종료나 크기 변경 때 위치를 강제 보정하지 않고, 모니터 분리로 토끼 전체가 화면 밖에 있을 때만 복구한다.
- 첫 실행에서 미결정 알림 권한은 macOS 승인 창으로 검토한다. 이전 거절은 존중하며, 꺼진 경우 앱 전용 알림 설정을 직접 열어 사용자가 바꿀 수 있게 한다.
- `ZicSprites`가 검수된 strip PNG/JSON을 읽는다. 스프라이트의 실제 발 기준점, 기본 신장, 프레임 지연을 그대로 적용하며 완료·실패 모션은 1회만 재생한다.
- 모션 테스트는 기본적으로 숨긴다. 설정에서 디버그 활성화 코드 `zcrenext`가 일치할 때만 전용 창과 우클릭 메뉴의 진입점을 표시한다. 전용 창은 스크롤 없이 8방향 이동·대기·좌우 잡힘·작업 중·완료·실패와 중지를 동시에 보여준다. 디버그 상태는 현재 실행에만 유지하며 끄거나 테스트 창을 닫으면 진행 중인 테스트를 멈춘다. 로그인 상태·작업·크레딧·알림 설정은 바꾸지 않는다.
- 상단 바와 지크 클릭 팝오버는 서로 다른 객체를 사용한다. 상단 바는 최근 알림 10개, 상세 현황은 전체 알림을 표시하며 비어 있는 경우에도 제목과 빈 상태 안내가 있다. 설정은 지크 표시/숨김 아래로 배치하고 산책 동작의 명칭은 활성화/비활성화로 통일한다.

- 상단 바 현황판은 670×560pt를 기준으로 화면에 맞춰 제한하고, 왼쪽 340pt에 기존 계정 현황을 두며 오른쪽에 서비스 상태를 표시한다. 좌우 목록은 독립적으로 스크롤한다.
- 공개 상태 API의 모델 목록·상태를 그대로 사용한다. 정상 판정은 평가된 데이터가 있을 때만 표시하고 알 수 없는 상태는 확인 중으로 처리한다. HTTP Date/Age와 경과 시간으로 서버 기준 5분 신선도를 확인하며, 서버의 stale 표시·조회 오류도 확인 중으로 처리한다. 현황창이 열린 동안 정상 응답 후 60초 간격으로 조회하고 재개방 시에도 캐시를 사용한다. 수동 조회의 최소 간격은 5초이며 실패 지연·Retry-After를 자동 조회와 공유한다. 계정 크레딧 폴링과 분리한다.

## 갱신과 전력 정책

- 작업 확인은 5초 목표 주기이며 응답 대기 중에는 겹쳐 실행하지 않는다. 첫 계정 연결은 최대 1,000개를 탐색하고 이후 기본 20개, 확인한 최근 겹침 구간이 20개를 넘으면 50개 단위로 이전 조회 시각 전후 60초까지 탐색한다. 추적 중인 미완료 작업은 최근 페이지에서 빠져도 개별 조회한다.
- 크레딧은 60초 주기와 작업 상태 전환 시 갱신한다. 전환 이후 15초 동안 후속 정산 조회를 하고 오류 시 마지막 확인 잔액을 표시한다. 크레딧 실패 때문에 성공한 작업 조회·완료 알림을 버리지 않는다. 다른 계정의 잔액 캐시는 사용하지 않는다.
- 오프라인과 잠자기는 요청을 멈추고 복구 때 재개한다. 오류 지수 백오프와 서버 Retry-After를 적용하며 명시적 새로고침도 서버 대기 시간을 우회하지 않는다.
- 대기 12fps, 산책·드래그·완료 24fps. 마우스 이벤트로 클릭 영역을 갱신하고 이동 중에만 20Hz 타이머를 사용한다. 숨김은 캐릭터 모션을 멈추며 데이터 감시는 유지한다.

## 상태와 알림 정책

| 상황 | 표시 / 동작 |
|---|---|
| 로그인 전 | 잔액 `—`, 연결 안내 |
| 미리보기 | 가상 데이터임을 항상 표시 |
| 정상 연결 | 서버의 사용 가능·예약·총 크레딧 그대로 표시 |
| 첫 조회 | 같은 계정의 저장 목록 복원, 기존 완료/실패 작업을 읽은 기록으로 보완. 과거 기록의 배너·소리·완료 모션 억제 |
| 진행 → 완료/실패 | 작업마다 1회 알림. 모델·종류·시작 시각으로 작업 구분 |
| 조회 사이에 생성·완료된 작업 | 이전 조회 이후 생성된 새 작업이면 알림 |
| 크레딧 임계값 이하로 내려감 | 1회 알림, 충전 등으로 회복된 후 재진입 시 재알림 |
| 네트워크/429/5xx | 마지막 데이터 유지, 갱신 지연 표시, 재시도 간격 증가 |
| 로그아웃/계정 변경 | 이전 계정 데이터와 추적 상태 제거 |
| 삭제된 추적 작업 | 완료로 알리지 않고 추적 종료 |
| 잠자기 | 조회/토끼 애니메이션 중지, 복귀 시 다시 확인 |

## 구성

`AppDelegate`는 메뉴 막대·팝오버·설정 창·토끼 패널을 연결한다. `CompanionStore`가 세션과 폴링 수명주기를 소유한다. `WebSession`은 앱 전용 WebKit 세션 안에서 `ReadSnapshot.js`를 실행한다. `ZCRECore`는 상태 해석·정밀 크레딧 값·알림 전이·재시도 정책을 UI와 분리해 검증한다.

모니터링 브리지는 세 가지 GET 경로만 허용한다. HTTPS·출처·로그인 세션을 검증하고, 요청 도중 계정/워크스페이스가 바뀌면 응답을 폐기한다. 프롬프트·파일 링크·토큰은 네이티브로 전달하지 않는다.

## 연결 방식 결정

2026-10-25 확인: ZCRE 공식 MCP 서버는 `https://mcp.zcre.ai/mcp`, 조회 범위는 `zcre:mcp:read`이며 인증 서버는 Clerk이다. 공개 메타데이터는 PKCE와 Client ID Metadata Document 지원을 공지하고 있다. Codex 연결 인증을 독립 앱에 복사하지 않기 위해 이번 버전은 별도 앱 웹 로그인을 사용한다.

배포 단계에서는 앱 전용 HTTPS 클라이언트 메타데이터/인증 등록을 준비하고 `ASWebAuthenticationSession` + PKCE + Keychain + 공식 MCP 조회 어댑터로 전환하는 것이 좋다. 서버 지원을 확인하기 전에는 임의 Client ID나 다른 제품의 인증 정보로 대체하지 않는다.

참고: [ZCRE MCP 안내](https://www.zcre.co.kr/mcp), [공개 리소스 메타데이터](https://mcp.zcre.ai/.well-known/oauth-protected-resource/mcp), [NSPanel](https://developer.apple.com/documentation/appkit/nspanel), [macOS 알림 권한](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications).

## 0.2.10 유휴 인사

한가할 때 45~90초 간격으로 웃으며 한 손을 흔든다. 작업·산책·드래그·완료·실패 등과 충돌하지 않도록 예약과 중단을 관리한다. 산책을 꺼도 인사는 가능하며 숨김·잠자기·동작 줄이기에서는 자동 인사를 하지 않는다. 디버그 모션 목록에도 일회 재생을 제공한다. 상세 동작은 [인사 모션](IDLE-GREETING-0.2.10.md)을 따른다.
