# 0.2.10 유휴 인사와 홍보영상 에필로그

지크가 웃으며 한쪽 손을 크게 좌우로 흔드는 `wave` 모션을 추가한다. 기존 정면 원화를 Grok 구독·sprite-gen으로 움직이고 한 번 재생 후 원래 자세로 돌아오도록 추출한다. 기준 신장 384px를 유지한다.

## 앱 동작

- 작업이 없는 상태에서 45~90초의 무작위 간격으로 예약한다. 한 번 인사한 뒤 새로운 간격을 선택한다.
- 산책 중에는 인사를 미룬다. 산책 때문에 예약 시각을 매번 초기화하지 않아 계속 산책해도 쉬는 구간에 인사할 수 있다.
- 산책 비활성화 상태에서도 화면에 보이며 한가하면 인사한다.
- 작업 시작·드래그·현황 카드 열기·완료/실패 반응·숨김·잠자기·동작 줄이기에서는 자동 인사를 중단하고 예약을 취소한다. 다시 한가해지면 새 간격을 둬 밀린 인사를 몰아 재생하지 않는다.
- 포인터를 올려둔 동안에는 새 인사를 시작하지 않는다.
- 대기 예약과 재생 종료는 하나의 취소 가능한 Task가 소유한다. 서버 요청이나 상시 폴링 타이머는 추가하지 않으며 별도 효과음·알림도 발생시키지 않는다.
- 디버그 창에 `손 흔들기 · 한 번 재생`을 추가했다. 전체 버튼이 한 번에 보이도록 창 높이를 560pt로 조정했다.

## 홍보영상

v4.2는 v4.1의 고정 확대된 약식 현황 2배·작업 현황 1.4배를 유지하고 마지막 3초만 손 흔들기 모션으로 바꾼다. 기존 1080p·30fps·39.8초 구성과 음악·효과음을 유지한다. 앱에서는 전체 인사 후 복귀하고, 영상 에필로그에서는 웃으며 인사하는 앞부분을 사용한다.

실제 운영 서버 작업을 만들거나 실패시키는 검사는 하지 않는다. 회귀 검사와 빌드 결과, 모션 원본과 최종 리소스 확인은 별도 검증 기록에 남긴다.

## 알림 표시 정리

상단 바의 크레딧 뒤에 붙던 `•5` 같은 미확인 알림 숫자를 제거했다. 툴팁과 접근성 설명에서도 해당 개수를 제거하고 최근 알림 목록·보관·완료/실패 배너는 유지한다.

## 검증

Swift 코어 49개, 앱 35개, JavaScript 39개 통과. 산책 중 예약 보존·작업/숨김 후 재예약·모션 우선순위·지원 크기의 손/귀 수용을 검사했다. 4차 생성본의 중앙 정사각형 캔버스를 채택했고, 단발 모션이 허용하는 `anchor none`으로 다시 추출했다. 앱은 첫 프레임의 발 중앙을 고정 기준점으로 사용한다. 각 프레임을 따로 이동시키지 않았다. 제작 검토는 `reviews/2026-10-26-wave-motion.json`에 있다.
