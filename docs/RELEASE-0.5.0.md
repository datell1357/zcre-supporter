# v0.5.0 (32) 직접 배포

- 지크의 이미지·영상·오디오·도구 메뉴에서 선택한 ZCRE 기능을 앱 안의 공용 작업 창에서 열고 같은 창에서 전환한다.
- ZCUT 연결, 파일 선택, 로그인 팝업, 영상 내보내기 및 MP4 저장을 macOS 창에서 처리한다.
- 세로 영상 변환을 작업 창의 도구 목록에 추가한다.
- 기존 작업 감시·크레딧 조회 주기는 유지한다.

검증 범위는 `scripts/test.sh`, Universal 빌드·Developer ID 서명·Apple 공증·Gatekeeper 검사와 [ZCUT 실제 계정 QA](ZCUT-WORKSPACE-QA.md)로 나눠 기록한다. 직접 배포 성공은 Mac App Store 심사 승인이나 모든 생성 모델의 실사용 검증을 의미하지 않는다.
