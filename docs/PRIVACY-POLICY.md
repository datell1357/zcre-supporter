# ZCRE 서포터 개인정보 처리방침

시행일: 2026년 11월 4일

ZCRE 서포터는 사용자가 연결한 ZCRE 계정의 크레딧·작업 현황과 서비스 상태를 Mac에서 보여 주는 도우미 앱입니다. 이 방침은 서포터 앱이 처리하는 정보와 사용자의 제어 방법을 설명합니다.

## 1. 개발자에게 전송하는 정보

서포터 개발자는 별도의 수집 서버, 광고 SDK, 앱 사용 분석 SDK 또는 자동 진단 업로드를 운영하지 않습니다. 사용자의 계정 정보·크레딧·작업 내용·마우스 위치·오디오 내용이 서포터 개발자에게 전송되지 않습니다.

## 2. ZCRE 및 로그인 제공자와의 통신

사용자가 연결하면 앱 전용 WebKit 창에서 ZCRE와 선택한 로그인 제공자의 인증 과정을 거칩니다. 쿠키와 웹 저장소는 WebKit이 관리하며 다른 브라우저의 세션을 복사하지 않습니다. 서비스 요청에는 해당 서비스가 인증과 응답에 필요한 쿠키·계정 및 워크스페이스 식별자와 일반적인 네트워크 연결 정보가 전달될 수 있습니다. ZCRE 및 로그인 제공자가 자체적으로 처리하는 정보에는 해당 서비스의 개인정보 처리방침이 적용됩니다. 해당 방침은 로그인·서비스 페이지에서 확인할 수 있습니다.

앱은 ZCRE의 크레딧, 작업 식별자·종류·모델·상태·시각, 워크스페이스 정보와 동시 생성 현황을 조회하여 표시합니다. 결과 창을 열면 결과 메타데이터와 HTTPS 미디어 주소를 일시적으로 사용하고, 재생을 선택하면 해당 서비스 또는 미디어 제공 서버에서 콘텐츠를 불러옵니다. 앱은 생성·결제·충전 요청을 자동 실행하지 않습니다. 도구 바로가기는 사용자가 선택한 ZCRE 웹 페이지를 엽니다.

공개 서비스 상태는 ZCRE 공개 API에 쿠키·계정 토큰·작업 정보를 붙이지 않고 조회합니다.

## 3. 이 Mac에 보관하는 정보

- 캐릭터 표시·위치·크기, 산책, 소리, 알림 종류 및 앱 내 집중 모드 설정을 로컬 환경설정에 보관합니다.
- 최근 알림 최대 30개의 표시 문구·시각·상태와 기록 구분값을 앱의 로컬 Application Support 저장소에 보관합니다. 문구에는 작업 종류·모델·시작 시각 또는 크레딧 부족 시 잔액이 포함될 수 있습니다. 계정과 작업의 구분값은 SHA-256 해시로 보관하며 인증 토큰·결과 주소는 알림 파일에 보관하지 않습니다. 해당 파일의 접근 권한은 현재 사용자로 제한합니다.
- 로그인 쿠키와 웹 저장소는 앱 전용 WebKit 저장소에 남을 수 있습니다.
- 사용자가 다운로드를 선택한 파일만 사용자가 지정한 위치에 저장합니다. 미디어 주소와 이미지 캐시는 제한적으로 메모리에 보관합니다.
- 진단 내보내기를 직접 선택하면 앱·OS 버전, 연결 상태, 개수와 설정을 로컬 JSON에 저장합니다. 계정 식별자·잔액·작업 내용·주소·토큰은 제외하며 앱이 파일을 외부로 보내지 않습니다.

## 4. 권한과 기기 정보

알림 허용과 로그인 시 자동 실행은 선택 사항입니다. 마우스 이벤트·위치는 캐릭터 클릭·이동에만 사용하고 보관하거나 전송하지 않습니다. 타자 효과음이 다른 소리를 방해하지 않도록 macOS 오디오 실행 상태를 확인할 수 있으나 녹음·마이크 수집·오디오 내용 분석을 수행하지 않습니다. 네트워크 연결 상태는 조회 중지와 재개에 사용합니다.

## 5. 보관 기간과 삭제

로컬 설정과 WebKit 로그인 상태는 사용자가 변경하거나 연결을 해제할 때까지 남을 수 있습니다. 알림은 최대 30개로 제한합니다. 설정의 ‘연결 해제’는 이 앱의 WebKit 데이터와 계정 감시·로컬 알림 기록을 정리합니다. ‘전체 지우기’는 알림 목록을 비우고 이전 작업이 다시 나타나지 않도록 삭제 기준 시각을 저장합니다. ZCRE 계정이나 서버 작업 기록은 삭제하지 않습니다. 이미 다운로드한 파일은 사용자가 Finder에서 별도로 삭제할 수 있습니다. 앱 숨김은 데이터 삭제 기능이 아닙니다.

## 6. 데모 모드

미리보기 체험은 가상 작업과 앱에 포함된 샘플을 사용합니다. 샘플 재생·저장은 실제 계정 결과를 조회하거나 생성 크레딧을 사용하지 않습니다. 사용자가 ZCRE 도구 바로가기를 열면 해당 웹 서비스의 정책이 적용됩니다.

## 7. 문의 및 변경
