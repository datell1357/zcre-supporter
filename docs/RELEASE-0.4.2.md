# v0.4.2 · 로그인 창과 직접 업데이트 개선

- 계정 데이터 수신이 확인되면 연결 창과 로그인 팝업을 닫습니다. 감시용 웹 세션은 유지합니다.
- 이미 연결된 계정의 관리 창은 사용자가 닫을 때까지 유지합니다. 로그아웃·계정 전환 후 재연결이 확인되면 자동으로 닫습니다.
- 설정의 **업데이트 설치 및 재시작**으로 Sparkle이 DMG 다운로드, EdDSA 서명 검증, 앱 교체, 재시작을 처리합니다.
- 기존 GitHub 새 버전 확인은 12시간 간격을 유지하고 Sparkle의 별도 자동 조회는 끕니다. 사용자가 설치를 누르기 전에는 다운로드하지 않습니다.
- App Store 빌드에서는 Sparkle 의존성·프레임워크·피드 설정을 제외합니다.
- 타자음을 무조건 차단하던 다른 앱 오디오 감지를 선택 옵션으로 분리했습니다. 기본은 함께 재생하며, 원하면 **다른 앱 재생 중 타자음 쉬기**를 켤 수 있습니다. 효과음 음량은 기존 사용자 설정을 유지합니다.
- 타자음은 무한 반복 없이 약 1초 재생 후 장치를 해제하고 약 5초 쉽니다. 숨김·집중 모드·잠자기·음소거에는 재생하지 않습니다.
- 작업·크레딧·서비스 상태 감시 주기 및 튜토리얼 영상은 변경하지 않습니다.

v0.4.1까지는 직접 설치 기능이 없으므로 v0.4.2로 최초 업그레이드하는 한 번은 DMG 설치가 필요합니다. 이후 새 버전부터 앱 안에서 적용할 수 있습니다. 읽기 전용 DMG 안에서 실행 중이면 먼저 Applications에 설치해야 합니다.

업데이트 서명 키는 Mac Keychain의 `zcre-supporter` 계정에 보관합니다. 개인 키는 저장소나 릴리즈에 포함하지 않습니다. 배포 DMG 공증 후 `python3 scripts/make-appcast.py <DMG> --description "<변경 내용>"`로 피드를 만들고, DMG는 GitHub 릴리즈에, `updates/appcast.xml`은 main에 게시합니다. 파일이 변경되면 반드시 다시 서명합니다. 공식 연동 문서: https://sparkle-project.org/documentation/

확인 결과: Swift XCTest 9개·코어 58개·앱 50개(실다운로드 선택 검사 1개 생략), 브리지 50개, 패키징 5개가 통과했습니다. 실제 계정 연결 후 연결 창이 닫히고 바탕화면에 진행 작업 1개가 표시되는 것을 확인했습니다. 오디오 장치를 유지하는 다른 앱 때문에 기존 타자음 억제 경로가 활성화되는 것을 확인했습니다. 새 유한 재생 경로는 모의 플레이어로 다른 앱 오디오와 공존·양보 옵션·숨김·음소거·작업 완료 중단을 검증했습니다. 사용자가 기존 10% 음량에서 실제 타자음 출력을 확인했습니다. 별도 폴더의 공증된 이전 빌드 번호 후보(28, 신규 업데이터 포함)에서 공개된 v0.4.2를 내려받아 빌드 29로 교체하고 새 프로세스로 재시작하는 것을 확인했습니다. 교체된 앱의 서명·공증·Gatekeeper도 통과했습니다. 실제 공개 v0.4.1에는 새 업데이터가 없으므로 최초 DMG 설치 안내는 계속 적용됩니다.
