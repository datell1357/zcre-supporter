# macOS 업데이트

직접 배포본은 공개 GitHub 릴리즈로 새 버전을 감지하고, 설치는 Sparkle이 수행한다.

- 자동 확인: 시작 시와 이후 12시간 간격.
- 수동 확인: 설정의 ‘업데이트 확인’은 자동 확인 캐시와 분리하며 최소 60초 간격을 지킨다. 제한 중에는 다음 가능 시각을 표시한다.
- GitHub 403/429: 최소 1시간 및 서버 Retry-After를 수동·자동 모두 존중한다. 오프라인에는 조회하지 않는다.
- 설치: ‘업데이트 설치 및 재시작’을 누르면 Sparkle이 공증 DMG의 EdDSA 서명 검증·앱 교체·재실행을 처리한다. 자동 조회만으로 파일을 받거나 앱을 종료하지 않는다.
- App Store 빌드: 외부 업데이터 의존성·프레임워크·피드 설정을 제외하며 App Store에서 업데이트한다.
- v0.4.1 이하에서 최초 v0.4.2 이상 설치는 DMG를 사용한다. 이후부터 직접 설치 기능을 사용할 수 있다.
- 업데이트 목록은 정식 숫자 버전만 대상으로 하며 같은 태그의 재업로드는 버전 상승이 아니다.
- ZCRE 계정·작업·잔액은 GitHub에 전달하지 않는다. 작업 감시 일정과 독립적이다.

진단·검증 범위: [결과와 업데이트 안정성](RESULT-RELIABILITY.md). 설치·서명·게시 절차: [v0.4.2](RELEASE-0.4.2.md).
