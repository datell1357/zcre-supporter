# 0.2.20 원형 메뉴 글자 잘림 수정

56pt 버튼에 긴 이름을 한 줄로 배치하던 문제를 수정했다.
단어 경계에서 두 줄로 나누고 텍스트 영역 40×26pt, 글자 10.5pt, 아이콘 16pt, 간격 2pt를 적용했다.
원 크기와 버튼 위치는 유지한다. 접근성 이름과 툴팁에는 전체 이름을 제공한다.

Universal 빌드 통과. 실제 SwiftUI 뷰의 홈·이미지·영상 메뉴 렌더 결과를 육안 검수했으며
캐릭터 시트·고화질 변환·프레임 보간을 포함한 모든 이름이 원 내부에 표시됨을 확인했다.
