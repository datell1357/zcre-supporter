# v0.4.4 · 결과 저장 안정성과 업데이트 확인 개선

- 수동 업데이트 확인을 자동 확인의 12시간 대기와 분리했습니다. 최소 60초 간격과 GitHub 서버의 요청 제한은 유지하고, 대기 중에는 다음 확인 가능 시각을 안내합니다.
- 완료 결과 조회에 네이티브 시간 제한과 취소를 연결했습니다. 재조회 중 기존 결과는 유지합니다.
- 다운로드에 진행률·취소·저장 폴더 열기를 추가했습니다. 완전히 받은 파일만 최종 경로에 저장하며 실패한 수신으로 기존 파일을 덮어쓰지 않습니다.
- 만료된 결과 주소는 메타데이터 캐시를 건너뛰어 갱신한 뒤 한 번만 재시도합니다.
- 이미지 미리보기는 청크 단위로 받고 같은 이미지의 동시 요청은 하나로 합칩니다. 12MiB·1100px 제한은 유지합니다.
- 설정 상단에 현재 버전과 빌드를 표시합니다.
- 기능별 요청·성공·실패·취소 수와 처리 시간을 메모리에서 집계합니다. 사용자가 진단 내보내기를 실행할 때만 저장하며 URL·토큰·계정·프롬프트·오류 원문은 포함하지 않습니다.

작업 감시 5초·크레딧 60초 주기 및 작업 변화 후 정산 추가 확인 정책은 변경하지 않았습니다.

## 검증

- 회귀 검사 178개 통과(Swift 123개, 웹 브리지 50개, 배포 프로파일 5개), Universal 릴리즈 빌드 및 diff 검사 통과.
- `/Applications`에 설치한 v0.4.4 빌드 31의 실행 파일이 배포 후보와 같은지 해시로 확인.
- 설치된 앱의 기존 로그인 세션에서 창 없는 실계정 검사 13개 통과: 계정 조회, 5초 재조회, 초기 15초 정산 확인 이후 잔액 캐시, 연결된 네 SNS 메트릭, 서비스 상태, 수동 업데이트 확인·요청 제한, 기존 완료 결과 메타데이터·캐시·강제 갱신, 약 5.5MB 결과 파일 저장, 이미지 미리보기 디코딩, 표시된 창 없음.
- 새로운 생성·결제 요청 및 크레딧 사용 없음. 실계정 검사는 기존 완료 이미지로 진행했으며 영상·오디오 재생, 새 작업의 시작→완료 전환 및 OS 알림 화면은 이번 검사의 범위에 포함하지 않음.
- 앱과 DMG의 Developer ID 서명·Apple 공증 및 Gatekeeper 검사 통과.
