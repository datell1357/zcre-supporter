# 작업별 알림과 집중 모드 · 0.2.17 (20)

설정에만 두 섹션을 추가했다. 홍보영상과 원형 메뉴는 변경하지 않았다.

- 작업 종류별 알림: 이미지 / 영상 / 업스케일 / 오디오 / 기타. 기본 모두 켜짐. 모델 ID에 upscale이 있으면 매체보다 우선하여 업스케일 설정을 적용한다. 나머지는 서버 mediaType을 사용하고 알 수 없는 매체는 기타로 처리한다.
- 기존 완료·실패 알림 설정을 유지하며 그 아래 조건으로 작업 종류 필터를 적용한다. 끈 종류는 배너·시스템 알림·완료/실패 반응을 생략하고 작업 이력은 유지한다. 크레딧 부족은 작업 종류 필터와 별개다.
- 집중 모드: 지금 집중하기(다시 끌 때까지, 재시작 후 유지), 매일 예약(기본 22:00–08:00, 기본 비활성). 현지 시각으로 시작 포함/종료 제외, 자정 통과 지원, 같은 시각은 하루 종일. 즉시 모드가 예약보다 우선하며 즉시 모드를 끄면 예약이 적용될 수 있다.
- 집중 중에는 완료/실패/크레딧 부족의 새 시스템 알림·앱 배너·말풍선과 완료/실패 모션, 지크 효과음을 억제한다. 이미 시작된 반응·효과음과 대기 중 앱 배너도 중단한다. 기존 macOS 알림센터 이력은 삭제하지 않는다.
- 집중이 끝나도 억제한 알림을 다시 전달하지 않는다. 데이터 폴링·크레딧·진행 중 작업·서비스 상태 조회와 최근 알림 보관은 기존 경로를 유지한다. 일반 산책과 작업 중 시각 모션은 유지한다.
- macOS 집중 모드와 연동하지 않는 앱 자체 설정이다. 집중 중 설정의 알림 테스트 버튼은 비활성화한다. 명시적인 디버그 모션 테스트는 유지한다.
- 예약만 사용하는 경우 현지 분 경계에서 로컬 시간만 재평가한다. 새 API나 서버 요청은 추가하지 않았다. 잠자기에서는 타이머를 취소하고 복귀 시 재평가한다.

## 검증

Swift Testing 92개(54+38), XCTest 9개, JS 43개 통과. 추가 검증은 자정/낮 시간 경계, 시작=종료, 수동 우선순위, 업스케일 독립 분류, 설정 복원, 필터된 작업의 기록 유지/중복 방지다.

알림 서비스가 앱 번들을 요구하므로 비번들 테스트 러너에서 CompanionStore를 직접 생성하는 초기 통합 테스트는 실행 환경 오류로 중단됐다. 해당 테스트는 실제 OS 서비스를 만들지 않는 정책/이력 검증으로 변경했다. 실제 서버 작업을 새로 생성하는 테스트는 하지 않았다.

Universal release 빌드 및 서명 검증 완료, dist 앱을 0.2.17 (20)으로 교체했다. macOS 실행 서비스가 프로세스를 정지시켜 실제 설정 화면 확인은 미완료다. 직접 실행 파일 호출은 자동 승인 검토에서 명시적 우회 승인 부족으로 거절되어 실행하지 않았다. 설치된 앱의 실제 UI/소리 확인은 이후 필요하다.
