## 실제 마우스로 확인하는 순서

1. 작업표시줄 알림 영역의 지크 아이콘을 찾습니다. 접혀 있으면 **숨겨진 아이콘 표시(^)**를 엽니다. 아이콘 위에 마우스를 올리면 ZCRE 서포터 툴팁으로 구분할 수 있습니다.
2. 아이콘을 한 번 클릭합니다. 아래 작업표시줄에서는 **작업표시줄 근처에서 위로** 현황 팝업이 열리는지 확인합니다. Windows 화면 상단에 별도 고정 바가 생기지 않아야 합니다. 팝업에는 OS 제목 표시줄·최소화/최대화 버튼·별도 작업표시줄 버튼이 없어야 합니다. 팝업 안의 작은 ‘ZCRE 서포터’ 글씨는 콘텐츠 제목입니다.
3. 진행 작업 / 크레딧·지크 표시·설정·최근 알림 / 서비스 상태의 3열을 확인합니다. 화면이 작으면 열 안에서 스크롤할 수 있어야 합니다. 실제 크레딧·작업이 웹과 맞는지는 화면에서 직접 대조합니다.
4. 바깥을 클릭하거나 Esc를 눌러 팝업이 닫히는지 확인한 뒤 트레이에서 다시 엽니다. 여러 개의 현황 창이 중복해서 남지 않아야 합니다.
5. **설정**과 **상세 현황**을 각각 엽니다. 팝업이 닫히고 별도 일반 창이 정상적으로 열려야 합니다. 이 창들의 제목 표시줄은 의도적으로 유지합니다. 상세 현황의 기존 완료 작업에서 **결과 보기**가 열리는지 확인합니다. 생성 작업을 새로 제출할 필요는 없습니다.
6. 지크를 왼쪽 클릭합니다. 중앙 지크와 작업 문구를 가리지 않으면서 **이미지·영상·주짓수·오디오·닫기·캔버스** 여섯 버튼과 약식 현황이 보이는지 확인합니다. 여유가 있으면 현황은 위쪽에 열리며, 화면 가장자리에서는 현황과 버튼이 화면 안의 빈 공간으로 이동할 수 있습니다. 이미지/영상 하위 메뉴, 뒤로, 닫기를 확인합니다. 캔버스는 공식 `/studio/canvas` 페이지로 연결되며 자동 생성을 하지 않습니다.
7. 지크를 마우스로 잡아 좌우로 옮긴 뒤 놓습니다. 잡힘 모션, 커서 추종, 좌우 방향, 놓은 위치가 정상인지 확인합니다. 다시 클릭했을 때 메뉴가 정상적으로 열리고 바깥 클릭으로 닫히는지도 확인합니다.
8. 설정의 ‘지크 보이기’를 껐다 켜서 표시 상태가 돌아오는지 확인합니다. 설정을 다시 열어 선택이 유지되는지도 확인합니다. 현재 모니터 구성과 배율에서 먼저 확인하면 됩니다. 다중 모니터·배율 변경의 실기 검증은 별도 미검증 항목입니다.

설정의 **계정 열기**로 직접 연 웹 창은 계정 확인을 위해 유지됩니다. X로 닫아도 로그인은 보존됩니다. 처음 연결할 때의 로그인용 창은 검증된 스냅샷을 받으면 숨겨집니다. 계정 연결을 다시 확인할 때 로그아웃이나 ‘연결 해제’를 누를 필요는 없습니다.
