# v0.0.4 · macOS

## 변경

- 상단 바 현황판의 크리에이터 탭: 연결 SNS 수치와 최근 30일 실제 수집 추이를 2×2 그래프로 표시한다. HTML이 아닌 JSON의 허용 필드만 전달한다.
- 메트릭은 탭을 열 때 조회하고 10분간 메모리 캐시를 사용한다. 계정 변경 시 비우며, 닫힘·오프라인·잠자기 때 요청을 중단한다.
- 서비스 상태는 2열로 표시하며 현재 21개 서비스를 스크롤 없이 확인할 수 있다. 모델명과 상태 색상을 유지한다.
- 직접 배포본은 시작 시와 12시간마다 GitHub의 정식 새 버전을 확인한다. 설치 파일의 저장소·아키텍처·파일 크기·SHA-256을 검증한다. 설치 파일을 연 뒤 Applications에서 직접 앱을 교체한다. 무인 교체/재실행은 지원하지 않는다.
- App Store 배포본은 외부 업데이터를 실행하지 않고 App Store 업데이트 경로를 제공한다.
- 미리보기에서 번들 이미지·영상·오디오 재생과 저장을 제공한다. macOS 지크 우클릭의 동작하지 않던 현황 항목을 제거했다.

작업 5초·평상시 크레딧 60초·서비스 상태 60초 감시는 유지한다. Windows 새 설치 파일은 이 릴리즈에 포함하지 않는다. 기존 v0.0.3 Windows 테스트 배포는 유지한다.

## 배포·검증

- macOS 14 이상, Intel/Apple Silicon Universal.
- Developer ID Application 서명, Hardened Runtime, 타임스탬프를 사용한다.
- 앱과 DMG를 각각 Apple 공증한 뒤 티켓을 부착한다. 최종 검증 기록은 릴리즈 작업 폴더의 reports에 보관한다.
- 자동 검사: `bash scripts/test.sh`. 별도 명시적 검사로 공식 DMG 다운로드·SHA-256·격리 출처 속성을 검증했다.
- 실제 계정의 SNS 그래프와 업데이트 설정을 확인했다. 현재 서비스 전체 표시와 긴 모델명의 배치를 검토했다.
- 이 변경으로 App Store 심사 중인 0.0.3 (26)을 변경하거나 재제출하지 않는다.

## 튜토리얼

기존 v10 영상의 모션·메뉴·결과 재생을 보존하고, 새 현황판·서비스 상태·크리에이터 그래프·업데이트 설정 장면을 추가한다. 음악·효과음은 새 길이에 맞춰 기존 합성 원본에서 다시 배치한다. 1080p 및 모바일 720p H.264/AAC로 제공한다. 새 장면은 실제 앱 UI의 촬영 시점 상태이며, 고정 구도와 기존 자막 형식을 유지한다.
