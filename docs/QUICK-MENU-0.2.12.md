# 지크 원형 메뉴 · 0.2.12

지크 클릭 → 원형 메뉴 → 이미지 또는 영상 → 도구 선택 → 기본 브라우저의 ZCRE 공식 페이지 열기

- 첫 화면: 이미지 / 영상 / 현황 / 설정, 가운데 현재 크레딧과 작업 개수
- 이미지: 이미지 생성 / 캐릭터 시트 / 부분 수정 / 배경 제거 / 고화질 변환 / 크기 변환
- 영상: 영상 생성 / 고화질 변환 / 프레임 보간 / 영상 번역
- 현황: 기존 크레딧·동시 생성 한도 요약
- 분류 안에서 뒤로 버튼으로 첫 메뉴 복귀
- 닫기 버튼, ESC, 다른 창 클릭으로 종료. 모니터 가장자리에서는 원 전체가 화면 안에 있도록 위치 보정
- 지크를 끄는 기존 동작 유지. 이미지 드래그앤드롭·업로드·자동 생성은 없음
- 메뉴 열기 시 기존 현황 갱신 게이트만 사용하며, 분류 선택은 로컬 UI 상태 변경. 별도의 폴링이나 웹 미리 로딩 없음
- 2026-10-26 ZCRE 홈의 도구 링크와 공개 웹 클라이언트의 영상 고화질 변환 경로를 기준으로 작성
- 브라우저 로그인은 기존 기본 브라우저 세션을 사용하며, 앱의 로그인 토큰을 브라우저로 전달하지 않음

검증: Swift 92개, JavaScript 43개 총 135개 통과. 공식 HTTPS 경로와 이미지·영상 분류, 영상 고화질 변환 옵션을 검사

실행 확인: 지크 클릭 시 원형 메뉴, 이미지 도구 6개·영상 도구 4개, 뒤로 가기, 현황 연결을 실제 앱에서 확인했다. 진행 중인 실제 작업 2개와 크레딧 변동도 메뉴·간단 현황에 동일하게 반영됐다.
