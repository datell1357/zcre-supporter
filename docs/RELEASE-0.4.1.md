# v0.4.1 · macOS 설치 창 개선

사용자 지정 버전 v0.4.1 (빌드 28). 직전 공개 버전은 v0.0.4이며 업데이터가 v0.4.1을 더 높은 정식 버전으로 판단하는지 검사한다.

- ZCRE의 다크·민트 테마로 DMG 설치 창을 새로 구성했다.
- 앱과 Applications 아이콘을 나란히 배치하고 드래그 방향·2단계 안내를 넣었다.
- Finder 이름표의 중앙 정렬과 대비, 한글 파일명 좌표, 창 하단 잘림을 조정했다.
- 1×/2× 배경과 재현 가능한 DMG 패키징 스크립트를 추가했다.
- 앱과 DMG를 Developer ID로 서명하고 Apple 공증 및 티켓 검증 후 배포한다.
- 앱의 기존 기능과 작업·크레딧·서비스 상태 감시 주기는 유지한다.
- 릴리즈 첨부는 DMG 1개만 제공한다. 튜토리얼은 README의 독립 영상 플레이어를 유지한다.

검수: 실제 Finder에서 DMG를 열어 전체 창·아이콘·문구 정렬을 확인했다. 최종 버전은 앱/DMG 서명·공증·Gatekeeper·내부 앱 티켓과 Finder 메타데이터를 검증한다. 새 계정 작업 생성부터 완료까지의 종단 간 검증을 새로 수행한 버전은 아니다.

패키징 재현: [설치 창 구성](INSTALLER-DESIGN.md). 기존 기능: [v0.0.4](RELEASE-0.0.4.md).
