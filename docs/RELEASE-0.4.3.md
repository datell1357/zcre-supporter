# v0.4.3 · 크리에이터 메트릭 새로고침 개선

- 새로고침 제한이 끝나면 열린 화면에서 버튼이 다시 활성화됩니다.
- 크리에이터 탭을 보는 동안에만 10분 간격으로 자동 조회합니다. 수동 조회는 자동 조회 캐시와 별개이며, 최소 60초 간격과 서버의 재시도 제한을 지킵니다.
- 조회 중이거나 조회에 실패해도 마지막으로 받은 수치와 그래프를 유지합니다. 서버 수집 시각과 앱의 마지막 성공 조회 시각을 따로 표시합니다.
- GitHub에서 v0.4.2를 설치한 사용자는 설정의 **업데이트 설치 및 재시작**으로 적용할 수 있습니다. 처음 설치할 때는 Apple 서명·공증이 완료된 DMG를 사용하세요.

검증: 설치한 앱에서 실제 계정의 네 채널 그래프와 두 조회 시각을 확인했습니다. 화면을 띄우지 않는 모의 응답 검증에서 60초 후 버튼이 다시 활성화되고 수동 조회 중 네 그래프가 유지되는 것을 확인했습니다. macOS Universal DMG 및 내부 앱의 Developer ID 서명·Apple 공증을 검증했습니다.
