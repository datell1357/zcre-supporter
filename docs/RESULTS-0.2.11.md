# 작업 패널과 결과 보기 · 0.2.11

- 상단 바 현황은 왼쪽 진행 중 작업 / 가운데 계정·최근 알림 / 오른쪽 서비스 상태의 세 패널이다
- 진행 중 작업은 기존 스냅샷을 재사용한다. 작업명·상태·시작 시각·경과 시간을 표시하며 웹의 해당 작업으로 연결한다. 진행률이나 완료 예정 시각을 추정하지 않는다
- 최근 완료 알림을 누르면 해당 작업의 결과창을 연다. 여러 결과 선택, 이미지 미리보기, 명시적 영상·오디오 재생, 결과 웹페이지 열기, 저장 위치 지정 다운로드를 지원한다
- 기존 알림의 해시를 현재 스냅샷과 연결하므로 작업 ID·프롬프트·서명 URL을 알림 파일에 새로 저장하지 않는다. 현재 스냅샷에서 찾을 수 없는 오래된 알림은 기존 웹 이력으로 연결한다

## 요청과 자원 제한

- 기존 작업 5초·크레딧 60초 조회 경로는 변경하지 않았다
- 사용자가 결과창을 열 때만 `/api/v1/requests/{id}/outputs`에 인증된 GET을 보낸다. 토큰은 WebKit 안에서만 사용한다
- 결과 메타데이터는 계정별 최대 20개·30초 메모리 캐시이며 링크의 유효기간이 더 짧으면 먼저 만료한다
- 결과 조회는 최소 5초 간격이며 실패 시 자동 반복하지 않는다. HTTP 오류의 Retry-After를 적용한다
- 현재 결과 응답에 작은 썸네일이 없어 이미지는 결과 파일을 읽어 최대 1100px로 축소한다. 전송은 12MiB까지로 제한하고 초과하면 웹 열기·다운로드를 안내한다. 이미지 캐시는 메모리 24MiB·12개로 제한한다
- 영상·오디오에는 자동 재생이 없다. 재생 버튼 클릭 후에만 미디어를 불러오고 결과창을 닫거나 결과를 바꾸면 플레이어를 정지·해제한다
- 원본 다운로드는 사용자가 저장 위치를 선택한 뒤에만 실행하며 임시 파일로 스트리밍한다. 계정 변경 또는 결과창 닫기 시 취소한다
- 계정 전환·로그아웃은 캐시와 진행 중 조회를 폐기한다. 서명 URL을 로그나 설정 파일에 저장하지 않는다

## 검증

Swift 기존 84개 + 결과 URL/링크 검증 4개, JavaScript 기존 39개 + 결과 브리지 검증 4개 통과 (총 131개)
브리지 검증: 선택 작업당 GET 1회, 계정 경계, 경로 주입 차단, 불필요한 필드 제외, Retry-After와 자동 재시도 없음
실제 계정의 완료 알림 → 결과 조회 → 영상 재생과 저장 대화상자 열기·취소를 확인했다. SwiftUI VideoPlayer의 현재 macOS 런타임 충돌을 발견해 AppKit AVPlayerView로 교체한 뒤 영상 화면을 확인했다. 원본 저장 완료와 배터리 사용량은 별도 실측이 필요하다
