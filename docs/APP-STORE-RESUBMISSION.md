# Mac App Store 재제출 준비 · 2026-11-26

## 확인된 심사 결과

- 제출 `2be2a8ca-2858-4bc9-9ed6-63324fd27c26`, 앱 버전 `0.0.3 (26)`은 2026-11-25 심사에서 거절됐다.
- **4.2 최소 기능:** 심사자는 앱 경험이 웹 탐색이나 웹 브라우저와 충분히 구별되지 않는다고 판단했다.
- **4.1(b) 모방 앱:** 심사자는 `zcre.ai`와 유사한 내용과 제3자 브랜드 사용 관계의 설명 부족을 지적했다.
- GitHub 직접 배포용 v0.5.0 (32)의 공개는 이 거절을 해소하거나 App Store 승인을 뜻하지 않는다. 특히 앱 내 웹 작업 창은 4.2 평가에 불리할 수 있다.

## 같은 거절을 반복하지 않기 위한 출시 게이트

1. **브랜드 권한 증빙:** ZCRE 권리자가 서명한 허락 문서 또는 공식 도메인 이메일의 명시적 회신을 보관한다. 권리자 법인/개인명, ZCRE·지크·로고·도메인 사용, Mac App Store 배포, 이 개발자 계정과 Bundle ID, 기간·철회 조건, 연락처가 들어가야 한다. `zcre.ai`와 `zcre.co.kr` 및 `zcut.ai`의 운영 관계도 설명받는다.
2. **네이티브 기능 입증:** 메뉴 막대의 크레딧·진행 현황, 데스크톱 지크, 작업별 완료·실패 알림, 결과 저장, 집중 모드가 웹 페이지 없이 앱 고유 동작으로 확인되는 화면 녹화와 스크린샷을 준비한다. 웹 작업 창만 연속해서 보이는 심사 동선은 피하고, 앱 내 웹 작업 창의 목적과 범위를 심사 메모에 설명한다. 이 입증만으로 4.2 통과를 보장하지 않으므로 필요하면 웹 도구를 기본 동선에서 분리하거나 추가 네이티브 기능을 구현한다.
3. **심사 계정:** 심사 전용 ZCRE 계정을 준비한다. 로그인·생성 기록 열람·완료된 이미지/영상/오디오 결과·크레딧·진행 중 작업 알림을 재현할 수 있게 한다. 계정이 없거나 결과가 비면 심사자는 웹 래퍼만 보게 된다. 로그인 방법과 2단계 인증 대안을 심사 메모에 적고 암호는 App Store Connect 보안 입력란에만 넣는다.
4. **제출 후보 QA:** 직접 배포 DMG와 별도로 Mac App Store 샌드박스 빌드를 만들고 `0.0.3 (26)`보다 큰 빌드 번호를 사용한다. 14인치 MacBook Pro와 실제 일반 사용자 계정에서 설치→로그인→권한 요청→메뉴 막대→데스크톱 지크→작업 시작·완료·실패→알림→결과 저장→재실행을 확인한다. 웹 작업 창의 ZCUT 연결·파일 선택·내보내기도 샌드박스에서 다시 확인한다. GitHub 서명·공증 테스트는 App Store 샌드박스 검증을 대신하지 않는다.
5. **메타데이터 일치:** 앱 설명·스크린샷·개인정보 레이블·연령 등급·지원 URL이 제출 빌드의 실제 동작과 일치하는지 확인한다. 제출 화면에는 새 빌드를 선택하고 오래된 0.0.3 스크린샷을 재사용하지 않는다.
6. **Review Notes:** 4.1 권한 문서와 4.2 네이티브 기능 근거를 첨부하고, 심사자가 첫 실행부터 핵심 기능을 3분 안에 볼 수 있는 단계별 안내 및 데모 영상을 제공한다. 이 문서와 실제 증빙 준비가 끝나기 전에는 재제출하지 않는다.

## ZCRE 팀에 요청할 것

- 브랜드·캐릭터·콘텐츠 및 도메인 사용을 포함한 **Mac App Store 배포 서면 승인**, 권리자/운영 주체 확인과 심사 문의 담당자.
- `zcre.ai`와 `zcre.co.kr`, `zcut.ai`의 공식 관계를 설명하는 문구 또는 공개 링크.
- 만료되지 않는 심사용 계정과 비과금 샘플 완료 결과, 테스트용 작업 시작/완료/실패 재현 경로. 가능하면 리뷰 기간 동안 계정 및 데이터 유지.
- 현행 앱 내 웹뷰 사용이 서비스 약관·OAuth·ZCUT 파일 저장 정책상 허용되는지 서면 확인. App Store 샌드박스에서 필요한 도메인, 로그인 리디렉션, 파일 권한 목록.
- 서버 조회량과 계정 테스트에 제한이 있다면 사전 안내. 심사 중 시스템 상태와 크레딧 표시 오류의 연락 창구.

## 상태

이 문서는 준비 목록이다. 서면 권한과 심사 계정, Mac App Store 후보의 실기기 QA 및 App Store Connect의 새 빌드 선택은 아직 완료 증빙이 없다.
