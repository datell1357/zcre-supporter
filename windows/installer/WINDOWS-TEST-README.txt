ZCRE Supporter v0.0.3 - Windows x64 TEST
======================================

Windows 이식판 테스트 버전입니다. 전체 실기기 기능 검증을 완료한 정식 Windows 버전이 아닙니다.
MSI 버전은 0.0.3이며 앱 내부 개발 빌드 버전은 0.2.20.1입니다.
정확한 소스 커밋은 같은 폴더의 BUILD-PROVENANCE.json을 확인하세요.

설치와 실행
- Windows 10 x64 build 19044 이상 또는 Windows 11 x64가 필요합니다.
- .NET 8 런타임을 포함합니다. Microsoft Edge WebView2 Evergreen Runtime은 별도로 필요합니다.
  공식 다운로드: https://developer.microsoft.com/microsoft-edge/webview2/
- 실행 중인 ZCRE를 먼저 정상 종료한 뒤 MSI를 실행하세요.
- 현재 사용자에게만 설치하며 관리자 권한, 자동 실행, 트레이 아이콘 자동 고정을 요청하지 않습니다.
- 설치 위치: %LOCALAPPDATA%\Programs\ZCRE Supporter
- 시작 메뉴의 ZCRE Supporter Windows Test로 실행하세요. 설치가 끝나도 앱을 자동 실행하지 않습니다.
- 이 테스트 설치 파일과 앱은 코드 서명되지 않았습니다. Windows 보안 설정을 변경하지 마세요.

데이터
- 설치 파일에 로그인 세션, 사용자 설정, 작업 이력, 인증서, 로그를 포함하지 않습니다.
- 앱의 기본 사용자 데이터 폴더는 %LOCALAPPDATA%\ZCRE Supporter입니다.
- 개발용 --data-dir 폴더를 자동 복사하거나 이관하지 않습니다.
- 설치/제거 정의는 앱 설치 파일과 설치기 소유 HKCU 항목만 관리하며 사용자 계정 데이터 폴더를 지우지 않습니다.
- Windows 앱 제거 기능으로 제거할 수 있습니다. 실제 설치/업데이트/제거 실기 검증은 아직 완료하지 않았습니다.

포함된 수정과 검증
- 원형 메뉴 외부 클릭 닫기, 메뉴/펫 클릭 제외, 후크 수명 정리.
- 트레이 위쪽 현황판 내용의 짧은 표시 효과, 방향/작업영역/DPI 배치, 애니메이션 비활성 대응.
- Windows App SDK 알림 활성화/프로필 경계/IPC와 로컬 테스트 알림 이력 분리.
- Core 987개와 메뉴/트레이/레이아웃/미디어/알림 데이터 자동 검사를 통과한 소스입니다.
- 실제 제품의 메뉴 열기/외부 클릭 닫기, 기존 계정 조회, 기존 영상 재생/저장을 확인했습니다.
- 패키징 시 깨끗한 publish 파일만 포함하고 MSI 추출 파일의 SHA256 일치를 검사합니다.

남은 미검증
- 실제 알림 센터 카드 클릭과 라이브 배너 활성화, 이번 진단 GUI 저장 완료.
- 실제 트레이 클릭/탐색기 재시작, 재부팅/로그인 자동 시작.
- 실제 Windows 11, 혼합 DPI/다중 모니터, 모든 모션/드래그 및 미디어 형식.
- 유료 생성/정산의 모든 전이와 장시간 감시. 검증 목적으로 크레딧을 사용하지 않았습니다.
- 개발용 앱과 다른 경로에 설치한 경우 기존 Windows 알림 등록의 활성화 경로도 확인이 필요합니다.

트레이 항상 표시
Windows는 앱이 알림 영역 아이콘을 자동 고정하는 공식 API를 제공하지 않습니다.
숨겨진 아이콘(∧)에서 지크 아이콘을 알림 영역으로 직접 끌어 놓거나,
앱 설정의 '트레이 아이콘 표시 설정 열기'에서 표시할 아이콘을 직접 선택하세요.
